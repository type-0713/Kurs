# Kurs — LingoSphere 3D: Cyber English Universe

> Zamonaviy 3D interaktiv animatsiyali, 8 xil kiber-o‘yinlarga boy, sof insoniy talaffuz (Studio HD Audio & Speech Recognition) va sun‘iy intellekt murabbiyiga ega keng qamrovli ingliz tili platformasi.

---

## 🚀 Asosiy Imkoniyatlar (Features)

### 🎙️ 1. Neural Voice & Pronunciation Studio (Talaffuz Laboratoriyasi)
- **Matn kiritib eshitish (Studio HD Audio)**: Istalgan matn yoki so‘zni yozib, toza insoniy native American/British talaffuzda eshitish.
- **Jonli Karaoke Yoritilishi**: Ovoz yangrayotganda gapdagi har bir so‘z birma-bir neon yoritiladi.
- **Audio Visualizer**: Jonli kiber audio to‘lqinlar ekvivalent animatsiyasi.
- **AI Mikrofon Tahlili (0-100%)**: Mikrofonga gapiring, sun‘iy intellekt talaffuzingizni fonetik aniqlikda baholaydi va xatolarni ko‘rsatadi.

### 🧠 2. 4 Asosiy Ko‘nikma (Core Skills Hub)
- 📖 **Reading Studio**: Qiziqarli maqolalar, har bir so‘z ustiga bosganda darhol ma‘nosi, fonetikasi va audiosi chiquvchi **Instant Word Inspector**, WPM tezlik o‘lchagich va testlar.
- 🎧 **Listening Arena**: Aeroport va biznes audio dialoglari, **Smart Dictation** (diktant diff checker bilan) va Minimal Pairs quloq sinovi.
- 🗣️ **Speaking Hub**: **CyberLex AI** suhbatdosh bilan real vaqtda ovozli muloqot va talaffuz tahlili.
- ✍️ **Writing Workshop**: **Cyber Speed Typing** poygasi (WPM, aniqlik %) va **Error Surgeon** grammatik xatolarni tuzatish trenajyori.

### 🎮 3. 8 xil Kiber O‘yinlar Zali (Arcade Citadel)
1. ☄️ **Cyber Meteor Defender**: Tushayotgan so‘zlarni tezda yozib lazer bilan yo‘q qilish.
2. 🃏 **3D Hologram Memory Matrix**: 3D kartalarni aylantirib inglizcha-o‘zbekcha juftliklarni topish.
3. 🔮 **Word Alchemist (Scramble)**: Aralashgan 3D harflardan so‘z yasash.
4. 🛡️ **Cyber Shield (Hangman)**: Yashiringan so‘z harflarini topib kiber qalqonni qutqarish.
5. 🎯 **Odd One Out**: 4 ta so‘z orasidan mantiqan begona so‘zni topish.
6. ⚖️ **True or False Blitz**: Ingliz tili qoidalari bo‘yicha tezkor rost/yolg‘on testi.
7. 🏗️ **Sentence Architect**: Gap sintaksisini to‘g‘ri terish.
8. ⚡ **30s Speed Lightning**: 30 soniyalik tezkor bilim poygasi.

### 📚 4. Vocab Vault (Shaxsiy Lug‘at Tizimi)
- O‘quvchi o‘zining shaxsiy so‘zlarini qo‘shishi, avtomatik audio talaffuz biriktirilishi va `localStorage`da saqlanishi.
- 3D Flip Flashcards kartalari.

### 🏆 5. Profil, Kunlik Baho va Faolliklar (Achievements & Stats)
- **Official Daily Grade (Kunlik Baho)**: Katta A+, A, B+ nishoni, 5 ta yulduz va o‘zlashtirish foizi.
- **Today's Live Activities**: Kun davomida qilingan barcha mashqlar tarixi va olingan XP ballari.
- **7-Day Consistency Map**: Haftalik faollik kiber-grafiki.
- **Daily Quests Checklist**: Kunlik 4 ta vazifa va progress bar.

### 🌓 6. Dark & Light Mavzular
- 🌙 Dark Cyber Mode
- ☀️ Light Crystal Mode
- 3D Three.js kosmik zarrachalar foni bilan moslashuvchi zamonaviy dizayn.

```bash
# Paketlarni o‘rnatish
npm install

# Mahalliy serverda ishga tushirish
npm run dev
```
